## Code from "Classic Computer Science Problems in Swift" by David Kopec translated to Dart

The book: [Classic Computer Science Problems in Swift](https://www.manning.com/books/classic-computer-science-problems-in-swift) by David Kopec, Manning, March 2018, Apache License

Dart: https://dart.dev/ 

To run the first example, enter the project directory and run from the command line:

```dart bin/classic_computer_science.dart 01_fib```

To debug the first example in VSCode, edit the `args` field in `.vscode/launch.json`
